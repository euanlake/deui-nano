Deui is a simple and elegant interface for Decent Espresso machines

Install DEUI Nano firmware on your controller. Connect via USB using Chrome or Edge.

Firmware install requires Chrome or Edge on desktop. Open this page over HTTPS or localhost to install firmware.

Waveshare Knob 1.8 boards expose two USB serial ports depending on cable orientation — select the ESP32-S3 port. See flashing docs for details.
